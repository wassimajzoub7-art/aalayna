It is kept in this tab's session storage only: never in a link, never saved to disk, and gone when the tab closes. The rest of this page works without it.

How to onboard
  1. Create an admin key once in the Supabase SQL editor (the insert is at the top of supabase/admin.sql) and connect with it here.
  2. Register the venue. Take the brand colour, background and font from their menu or Instagram; pick a menu pack if one exists in venues/.
  3. Open Manage on the new row. Send the owner editor and owner dashboard links to the owner only: each carries the owner key, and the page keeps it after the first visit.
  4. Guests do not use a venue link. Staff open a bill on the dashboard's Live floor and send its Guest bill link, a chk_ key for that bill only. The venue's gst_ key only reads the published menu.
  5. Demo payments stays on until the venue's payment provider confirms real payments; then switch it off here.
  6. If a key leaks, rotate it in the venue's panel and send the new links. The old key stops working at once.
